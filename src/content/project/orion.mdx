## Overview

A fullstack web application designed for personal knowledge base management using vector-based Retrieval-Augmented Generation (RAG) to efficiently answer questions and summarize content from personal documents.

## Features

- **Vector RAG**: Advanced retrieval system for quick and accurate responses
- **Document Management**: Organize and index personal documents
- **Question Answering**: Natural language queries on your knowledge base
- **Summarization**: Automatic content summarization capabilities

## Technology Stack

- Fullstack web application
- Vector database integration
- RAG implementation for enhanced AI responses
